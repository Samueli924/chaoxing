### 4.4 实测中发现的其它问题（均已修复）

| 问题 | 修复 |
| --- | --- |
| 自检的视频信息请求缺少播放器 Referer，`ananas/status` 返回 403 | 与学习时的请求保持一致 |
| 每章固定请求 7 个标签页 | 遇到不存在的标签页（模板 `mArg = $mArg` 未填充）即停止，请求数约减少 60% |
| 加密字体解码后出现部首字符（如"胸⻣""⻝堂"） | 补充 CJK 部首补充区到汉字的映射 |
| 重做时再次打开题目页只会得到已批阅页面，重做从未真正执行 | 改为调用网页"重做"按钮使用的 `/work/retest` |
| 作答记录"第1次"对应 `times=0`，此前按 1 开始请求详情 | 按页面中的 `showRecord` 参数取值 |
| 已批阅页面不公布答案时无法判断对错 | 读取每题的对错标记（`marking_dui` / `marking_cuo` / `marking_bandui`） |
