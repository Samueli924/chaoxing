# 图形界面（刷课助手）

不想每次打开终端敲命令的话，可以使用图形界面。它复用项目原有的刷课逻辑（`main.py` 和 `api/`），只是在外面加了一层本地网页界面，原有的命令行用法不受影响。

## 功能

- 账号登录，密码保存在系统凭据库（macOS 钥匙串 / Windows 凭据管理器），不写进配置文件
- 课程卡片显示每门课的完成进度，标出需要答题解锁的课程，支持搜索、一键选择未完成课程
- 实时显示总进度、正在播放的视频及剩余时间、每个章节的状态和运行日志
- 在界面里修改倍速、并行章节数、题库、推送通知等设置（写回 `config.ini`，命令行版共用）
- 多账号：添加多个账号，一键「全部开始」排队学习
  - 限制同时运行的账号数量，超出的自动排队
  - 相邻两个账号的启动时间在设定范围内随机错开
  - 每个账号使用独立的 cookie 文件和日志，互不干扰
- 题库使用本机 LM Studio 时，开始学习前自动加载模型，所有账号学完或停止后自动卸载，释放内存
- 学习期间阻止系统休眠，完成或出错时弹出系统通知

## 使用方法

先按项目 README 安装依赖（Python 3.13+），然后在项目根目录运行：

```bash
python gui/server.py
```

程序会自动用浏览器打开界面；关闭终端或按 `Ctrl+C` 即可退出。只想启动后台、手动打开地址时加 `--no-open`。

> Windows / Linux 想记住密码，需要额外安装 `keyring`：`pip install keyring`。不安装也能用，只是登录状态过期后要重新输入密码。

### macOS 独立应用

在 macOS 上可以打包成一个双击即可打开的 `.app`（需要安装 Xcode 命令行工具）：

```bash
gui/build_app.sh                     # 默认输出到项目上一级目录
gui/build_app.sh ~/Applications/刷课助手.app
```

应用会记住项目所在位置，移动项目文件夹后需要重新运行一次打包脚本。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `server.py` | 本地后台（Flask），只监听 127.0.0.1，接口需要启动时生成的令牌 |
| `worker.py` | 刷课进程，每个账号一个，调用 `main.py` 的逻辑并把进度以事件流上报 |
| `scheduler.py` | 多账号排队调度（同时运行数量、随机错开启动） |
| `configio.py` | 读写 `config.ini`，只改动指定的键，保留注释 |
| `keychain.py` | 系统凭据库读写 |
| `llm_manager.py` | 本地大模型（LM Studio）自动加载 / 卸载 |
| `platform_utils.py` | 系统通知、防休眠、在文件管理器中显示文件 |
| `static/` | 界面（原生 HTML/CSS/JS，无需构建） |
| `mac/` | macOS 外壳（Swift + WKWebView）和图标生成 |
| `data/` | 运行时数据：账号列表、各账号 cookie、日志（已加入 .gitignore） |

多账号设置保存在 `config.ini` 的 `[gui]` 小节：

```ini
[gui]
max_parallel_accounts = 2   ; 最多同时运行的账号数
stagger_min_minutes = 2     ; 相邻账号启动间隔（分钟，随机取值范围）
stagger_max_minutes = 5
auto_manage_local_model = true   ; 使用本机 LM Studio 时自动加载 / 卸载模型
```

### 使用本地大模型答题

在 LM Studio 中下载模型并打开本地服务（默认端口 1234），然后在设置的「题库」里选择「AI 大模型」：

- API 地址：`http://127.0.0.1:1234/v1`
- API Key：任意填写，例如 `lm-studio`
- 模型名称：LM Studio 中的模型标识，例如 `qwen3.8-27b-mlx`

### 联网搜索

在「AI 大模型」设置中填写 SearXNG 地址（例如 `http://127.0.0.1:8888`，需要在 SearXNG 的 `settings.yml` 中给 `search.formats` 加上 `json`）后，每道题会先搜索题干，再把搜索结果作为参考资料交给模型。如果再填写 SearXNG 的启动脚本，搜索服务没开时会自动启动，退出应用时一起关闭。

开启「自动加载 / 卸载本地模型」后，不需要提前手动加载模型。只会卸载这次刷课用过的模型；所有账号结束后会等待 15 秒再卸载，方便马上重新开始。

## 注意

- 倍速越高、同时运行的账号越多，越容易被平台检测为异常，建议倍速保持 1~1.5、同时运行账号不要太多。
